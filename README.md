# Weather Data Analysis

Weather Data Analysis using Python, Pandas and Streamlit Dashboard

## Project Overview
UK Weather data ka analysis. Is project me temperature, rainfall, aur weather patterns ka analysis kiya gaya hai. Dashboard me filters se year aur country select karke graphs change hote hain.

## 3 Key Findings
1. **Hottest Year:** Dashboard me Graph 1 se pata chalta hai kis saal average temperature sab se zyada tha.
2. **Hottest Month:** Graph 2 se pata chalta hai kis mahine me temperature sab se zyada hota hai.
3. **Temperature vs Humidity:** Scatter plot se pata chalta hai ke temperature aur humidity ka kya relation hai.
